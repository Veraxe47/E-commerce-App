# KeyDrop — React + Redux E-commerce 

**Student:** Saadi Okail

**Store:** KeyDrop — demo digital gift-card marketplace.

## Description
KeyDrop lets users browse digital gift cards and subscriptions, choose region/value variants, search and filter products, and manage a Redux-powered shopping cart.

## Technologies
React, JSX, Redux Toolkit, React-Redux, Vite, JavaScript, CSS, Lucide React.

## Main components
Header, Hero, ProductCard, CartDrawer, category filtering and product catalog.

## Redux state
The Redux store manages the cart with `addToCart`, `removeFromCart`, `changeQty`, `toggleCart`, `closeCart`, and `clearCart` actions.

## Features
- Responsive dark marketplace UI
- Product catalog
- Search and category filtering
- Region/value selection with different demo prices
- Redux shopping cart
- Quantity controls and remove/clear actions
- High-resolution scalable SVG product artwork
- Demo checkout (no real payment)

## Run
```bash
npm install
npm run dev
```
